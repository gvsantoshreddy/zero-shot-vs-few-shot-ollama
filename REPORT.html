Zero-Shot vs Few-Shot Prompting: Which Approach Works Better?

Assignment 1 · Topic 12 · Local Ollama experiment · Model: gemma3:4b

1. Abstract

This project compares zero-shot and few-shot prompting for sentiment classification and factual question answering. The same 20 test questions are evaluated with both approaches using a local language model. Three runs per question assess consistency, while reference answers support accuracy measurement. The experiment also records prompt tokens, output tokens and wall-clock response time.

2. Problem and Objectives

Choosing an effective prompt format can improve model answers, but examples add input tokens and require careful selection. The goal is to compare correctness, stability, speed and token costs on identical cases without sending data to a cloud API.

3. Methodology

Model: gemma3:4b via local Ollama. Dataset: 10 sentiment texts (positive/negative/neutral) and 10 short-answer factual questions. Trials: 3 for each prompt type and question, 120 runs total. Settings: temperature=0; num_predict=80. Fairness: same model, tasks, ground truth, and decoding settings; only the prompt examples differ. Test data and examples are separated.

8. Discussion

Compare the measured accuracy and consistency across tasks. Few-shot prompting may clarify output format or task boundaries, but uses more prompt tokens because examples are included. Zero-shot prompting is shorter and may be sufficient for familiar, unambiguous tasks. Small local models can make mistakes even with examples.

9. Example Selection Challenges

Examples must be representative, correctly labeled, concise, and different from the test questions. Too many examples can waste tokens, bias answers, or exceed context limits. A poor or misleading example may reduce performance. The three sentiment examples deliberately cover all three labels; Q&A examples cover geography, arithmetic, and science.

10. Limitations

The dataset is small and hand-written, results depend on the local Ollama model and hardware, exact matching can underestimate correct paraphrases, and temperature 0 does not always guarantee identical answers. A broader dataset, additional models, human grading and multiple random seeds would improve reliability.

11. Conclusion

The experiment shows how to choose a prompting method using evidence rather than assumptions. Use the results table to determine which method performed better for each task. Prefer zero-shot for simple tasks when brevity matters; try few-shot when labels, style or response format need demonstrations. Any final performance claim should be based on the recorded measurements above.
